SNDTEST: controlled OPNA (YM2608) audio-calibration stimulus, PC-9801-86.
Run it from a FRESHLY BOOTED DOS prompt with the line-out recorder already
rolling: the first sounds are the double-beep start marker (SEG 00).
Redirect it: SNDTEST > SNDTEST.TXT. Total run ~1.5-2 minutes, 45 segments.
ASSUMPTIONS (the printed frequencies depend on them):
  1. The OPNA clock prescalers 0x2D/0x2E/0x2F are NOT written: the power-on
     default is assumed (FM clock = master/6, SSG clock = master/4).
  2. Master clock 7.9872 MHz (the -86 board's crystal).
  3. FM tone f = fnum * 2^block * MULTI * (master/144) / 2^21 -
     the chip doubles the F-NUM first (ymfm_opn.cpp:354-387, die
     fmopna_impl.c:1270/:1358), and MULTI is the OPN table
     (0->x0.5, 1->x1, 2->x2, ...);
     SSG tone f = 124800 / TP (master/4, /16); ARTIC pacing = 307200 Hz.
MANIFEST FORMAT: 'SEG nn class=... ' = the segment's registers, computed
frequency and register-level gain in dB. '  W ss dd' = one register write
(0x188 <- ss, then 0x18A <- dd), in order. '  T art=XXXXXX' = a drum hit's
offset in ARTIC ticks from the segment start. '  ENDSEG art=XXXXXX bio=XXXX'
= the segment's measured ARTIC and BIOS-tick deltas (the delta covers
the hold PLUS the 0.5 s of written silence that closes it: a 1.500 s hold
reads ~614400 ticks, not 460800).
SAFETY: no disk, no DMA, 0x188/0x18A only (plus the 8259 slave IMR, replayed).
BEGIN:SETUP
SNDTEST: the card as found, READ-ONLY (only the select latch is written, which is how any of these is read). The -86 answers 01 at the chip-ID register. SSG register 7 is printed because it is the mixer/direction byte this probe writes: NP2kai seeds BF (all tones and noise disconnected, port B an output, port A an input - opna.c:137), NP2kai's OWN fmgen PSG seeds FF (both ports outputs - fmgen_psg.cpp:36), and our jt49 resets to BF too (jt49.v:245, a LOCAL PATCH following NP2kai). The die's SSG register-file reset values are NOT settled (they are NP2kai's, not die-verified), so read this byte as evidence about THIS machine rather than as a chip fact. IRQ12 (slave IMR bit 4) is masked for the whole run here and replayed in RESTORE.
  0x18A with 0x188=FF (chip ID; a -86 answers 01): FF
  0x18A with 0x188=07 (SSG register 7; the reset seed is BF): FF
  a 01/00 here says the card did not answer and every segment below is silent. This is NOT the as-found audio state: the reset seed BF means nothing had enabled the SSG yet.
END:SETUP
