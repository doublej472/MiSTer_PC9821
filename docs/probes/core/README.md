# Core-side probe captures

These are the CORE's half of a same-binary comparison: the same DOS probe programs whose real-Xe10
captures sit one directory up, run on this core on a MiSTer. They are evidence of what
the core did, never of what the hardware does.

The EGCP and GFX2 captures were made on the MiSTer with that build and copied here unmodified.
Decode them with the probe's own decoder (`tools/hwprobe/egcplane/egcplane_decode.py`,
`tools/hwprobe/gfxbenc2/gfxbenc2_decode.py`). `tb_pc9821_egc_xe10_pace` takes its CPU loop-shell
time and its load-path calibration from `EGCP-core.TXT`.

The XE10T `/OPNA2`, `/OPNA3` and `/AUDIT` captures were made on a DE10-Nano card from a DOS 6.20 hard-disk boot (SelSYS
entry 0, no EMM386, no sound driver), CPU Speed Full, with the probe typed at the prompt; each file
is the probe's own `XE10T.TXT`, read back from the disk image unmodified. Decode or compare them
with `tools/hwprobe/xe10t/xe10t_decode.py` (`MACHINE.TXT CORE.TXT` for the side-by-side table).
