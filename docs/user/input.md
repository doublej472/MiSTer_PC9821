# Keyboard, mouse and joypad

## Keyboard

Each PC key gives the PC-98 key at the same place, so Shift gives what the PC-98 prints on it:
Shift+`2` is `"`, Shift+`-` is `=`, and `:` is right of `;`. Set the OSD's **Keyboard** option to
your keyboard's layout; it changes only the four keys whose symbols differ (applied at the next key
press):

- `US`: `[`, `]` and `\` type `[`, `]` and `¥` (DOS's `\`, as in `cd \DOS`), and `` ` `` types `@`.
- `JIS`: every key types its own label, including `]`, `@` and `¥`.

## Mouse

The PC-98 bus mouse, driven by the mouse connected to the MiSTer. Mouse-driven DOS programs use a
driver such as `QMOUSE`; some games read the mouse directly and need none
([DOS setup](dos-windows.md#configsys-and-autoexecbat)).

## Joypad

The first MiSTer controller is the PC-98 joypad, read through the YM2608's joystick port as on the
Xe10: the D-pad and two buttons (**Button 1** and **Button 2** in MiSTer's button-mapping screen).
